# WWE Stars 元数据

本目录存放 WWE 明星角色设定文件，包含角色性格、职业生涯、历史恩怨等数据。

## 文件命名规范

```
{角色名}.md
例如: Stone_Cold_Steve_Austin.md
```

## 角色档案结构

每个 `.md` 文件包含以下内容：

### 1. 基本信息
- 中文名/英文名
- 擂台名 (Gimmick Name)
- 本名 (Real Name)
- 出生日期/地点
- 身高/体重
- 职业生涯时间线

### 2. 性格标签
- 核心特质 (3-5个关键词)
- 口头禅/标志性台词
- 标志性动作
- 人格雷达图 (冷血/傲慢/幽默等指数)

### 3. WWE 成就
表格形式，包含赛事、年份、成就名称

### 4. 职业生涯亮点
按时间段分期描述 (1996-1999 崛起期, 2000-2003 巅峰期 等)

### 5. 经典对手/恩怨
- 对手列表
- 关键剧情线

### 6. 摔角风格
- 站立技特点
- 招牌动作
- 终结技

### 7. 代表剧本
示例对白/场景描写，用于 AI 生成参考

### 8. 经典语录
角色标志性台词
